Политика конфиденциальности

Действует с 8 октября 2026 года

Политика описывает, какие данные получает приложение «ai-hub Google Ads MCP» (далее — приложение) и что с ними происходит. Приложение — это OAuth-клиент Google, через который официальный Google Ads MCP server на вашем компьютере обращается к Google Ads API от вашего имени.

Какие данные получает приложение

Приложение запрашивает одно разрешение Google — доступ к Google Ads API (https://www.googleapis.com/auth/adwords). Адрес почты, профиль, контакты и другие данные аккаунта Google оно не запрашивает.

Через это разрешение приложение читает данные Google Ads, которые вы или ваш ИИ-агент запрашиваете: идентификаторы и названия доступных рекламных аккаунтов, настройки и статистику кампаний, групп, объявлений и ключевых слов, справку по полям отчётов. Запись в аккаунт приложение не выполняет: инструменты сервера только читают данные.

Как используются данные

Данные используются только для ответа на ваши запросы в агентной среде, которую вы выбрали: показать статистику, построить отчёт, проанализировать кампании. Данные не используются для рекламы, не продаются и не применяются для обучения моделей искусственного интеллекта.

Где хранятся данные

У AI-hub нет серверов, через которые проходят ваши данные. MCP-сервер работает на вашем компьютере. Ключ доступа, который Google выдаёт при входе, хранится в файле на вашем компьютере. Данные Google Ads передаются от Google напрямую на ваш компьютер; AI-hub их не получает и не хранит.

Кому передаются данные

Данные, которые вы запрашиваете, попадают в агентную среду, выбранную вами, — например, в приложение Claude компании Anthropic. Там их обрабатывает модель ИИ поставщика среды по его собственным условиям и политике конфиденциальности. Другим третьим лицам данные не передаются.

Запросы к Google Ads API обрабатывает Google по Политике конфиденциальности Google.

Соответствие правилам Google

Использование и передача приложением информации, полученной от API Google, соответствуют Политике Google API Services в отношении пользовательских данных, включая требования об ограниченном использовании (Limited Use).

Как отозвать доступ и удалить данные

  • Отозвать доступ приложения: страница «Сторонние приложения с доступом к аккаунту» в аккаунте Google.
  • Удалить ключ доступа: удалить файл с учётными данными на своём компьютере.
  • Удалить данные из агентной среды: средствами её поставщика, например удалив переписку.

Безопасность

Ключ доступа хранится в файле, который может прочитать только ваша учётная запись на компьютере. Соединения с Google защищены шифрованием. Не передавайте файл с ключом другим людям: он даёт доступ к вашим рекламным аккаунтам.

Дети

Приложение предназначено для специалистов по рекламе и не рассчитано на лиц младше 18 лет.

Privacy Policy

Effective October 8, 2026

This policy describes what data the “ai-hub Google Ads MCP” app (the “app”) receives and what happens to it. The app is a Google OAuth client that the official Google Ads MCP server, running on your computer, uses to access the Google Ads API on your behalf.

Data the app accesses

The app requests a single Google permission: access to the Google Ads API (https://www.googleapis.com/auth/adwords). It does not request your email address, profile, contacts or any other Google Account data.

With this permission the app reads the Google Ads data that you or your AI agent request: IDs and names of accessible ad accounts, settings and statistics of campaigns, ad groups, ads and keywords, and report field metadata. The app does not write to your account: the server’s tools only read data.

How data is used

Data is used only to answer your requests in the AI agent environment you chose: showing statistics, building reports, analyzing campaigns. Data is not used for advertising, is not sold and is not used to train artificial intelligence models.

Where data is stored

AI-hub has no servers that your data passes through. The MCP server runs on your computer. The access credentials Google issues at sign-in are stored in a file on your computer. Google Ads data goes from Google directly to your computer; AI-hub neither receives nor stores it.

Who data is shared with

The data you request goes to the AI agent environment you chose, for example the Claude app by Anthropic. There it is processed by the provider’s AI model under that provider’s own terms and privacy policy. Data is not shared with any other third parties.

Requests to the Google Ads API are processed by Google under the Google Privacy Policy.

Compliance with Google policies

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Revoke the app’s access on the “Third-party apps with account access” page of your Google Account.
  • Delete the access credentials by deleting the credentials file on your computer.
  • Delete data from your AI agent environment using its provider’s tools, for example by deleting the conversation.

Security

The credentials file is readable only by your user account on the computer. Connections to Google are encrypted. Do not share the credentials file with anyone: it grants access to your ad accounts.

Children

The app is intended for advertising professionals and is not directed at persons under 18.
